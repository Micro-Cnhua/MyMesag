## 欢迎使用MyMesag

### 简单介绍

-   MyMesag是一个在安卓设备之间用于信息同步的开源app
    
-   它通过MQTT协议进行传输内容，并且使用端到端加密(E2EE)进行内容保护
    
-   归功于E2EE，我们也可以通过明文进行传输(tcp)，尽管收发信息的时间与设备会被截取
    
-   但是信息的内容却无法被截取查看
    
-   但除非您是在完全可信的内部网络进行传输，否则我们还是建议您使用加密传输(TLS)

## 额外帮助

### 发送端帮助

1.  作为发送端设备需要打开<同步设置>页面的[发送通知]按钮成为发送端
2.  [同步验证码短信]功能开启后会同步验证码，请确保您连接的MQTT服务器安全可信！否则即使我们使用了E2EE保证您信息的内容安全，但我们仍不推荐您开启该功能！
3.  在发送端设备的<应用选择>页面进行搜索并打开您需要同步发送给接收端的应用
4.  如果您需要同步来电和未接电话的消息，请搜索电话和联系人应用进行打开
5.  原生安卓会与国产魔改安卓的系统应用包命名不同，请搜索相似关键词进行查找(例如联系人/通讯录)

### 接收端帮助

1.  作为接收端设备需要打开<同步设置>页面的[接收通知]按钮成为接收端
2.  如果仅作为接收端设备，您不需要打开<应用选择>页面
3.  如果仅作为接收端设备且使用短信验证码接收功能，您不需要打开[同步验证码短信]功能

### 保活通知

1.  须在设置中打开MyMesag程序的[允许自启动]、[允许后台活动]两个功能以保活程序
2.  通知使用权在新版安卓系统中做出了安全限制，可以通过系统的提示进行解除限制开启MyMesag的通知使用权
